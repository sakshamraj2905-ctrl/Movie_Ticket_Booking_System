Movie Ticket Booking System

Project Description

The Movie Ticket Booking System is a Python-based command-line application that allows users to view available movies, check show timings, view available seats, book movie tickets, view booking details, and cancel tickets.

Features

- View available movies
- View movie languages, ticket prices, and formats
- View show timings
- View available seats
- Book one or multiple movie tickets
- Select seats for the booking
- Calculate total ticket price
- Generate a unique Booking ID
- View booking details
- Cancel a booking
- Make cancelled seats available again
- Exit the application

Technologies Used

- Python 3
- Command Line Interface (CLI)

Requirements

- Python 3.x
- A terminal or command prompt
- No external Python libraries are required

How to Run the Project

1. Clone the Repository

git clone https://github.com/sakshamraj2905-ctrl/Movie-Ticket-Booking-System.git

2. Open the Project Folder

cd Movie-Ticket-Booking-System

3. Run the Program

python main.py

The Movie Ticket Booking System will start in the terminal.

How to Use

After running the program, select an option from the menu:

1. View Movies
2. View Show Timings
3. View Available Seats
4. Book Ticket
5. Cancel Ticket
6. View Booking
7. Exit

Follow the instructions displayed in the terminal to perform the desired operation.
