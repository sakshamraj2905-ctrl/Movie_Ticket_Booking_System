# Movie Ticket Booking System

A simple terminal-based Movie Ticket Booking System developed using Python.

## Project Description

This project is a command-line based Movie Ticket Booking System. It allows users to view available movies, check show timings and available seats, book movie tickets, and view booking details.

The project is developed using basic Python concepts and can be executed directly through the terminal without any graphical user interface.

## Features

- View available movies
- View movie show timings
- View available seats
- Book movie tickets
- Select a movie
- Select a show timing
- Select a seat
- Prevent booking of already booked seats
- Generate a Booking ID
- Display ticket confirmation
- View booking details
- Terminal-based execution
